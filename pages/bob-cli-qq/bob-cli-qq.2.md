## Description

footer: add a LIFO overlay API on the ledger walker-footer status item. Live walk painters defer while an overlay is up, and popping repaints the current state. A hidden footer unhides for the overlay's lifetime, and a view-local fallback strip covers a hidden status bar. Both surfaces get aria-live, and the API never writes the vault or spawns bob.
